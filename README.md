# 📈 IDX Screener Dashboard — Hadi Lie

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://share.streamlit.io)

Web dashboard untuk screening saham IDX berbasis pola candlestick proprietary.

## 🚀 Buka Dashboard

👉 **[Klik di sini untuk buka dashboard](https://share.streamlit.io/USERNAME/screener_streamlit/main/app.py)**

## Fitur
- Upload file XLS dari RTI langsung di browser
- Scan 9 pola: BOA, ~BOA, P1, P2, P3, OL Berturut, SV, TT, Alert
- Tabel interaktif dengan warna
- Filter WL / Non-WL
- Tampilan dark mode

## Deploy Sendiri di Streamlit Cloud

1. Fork repository ini
2. Buka https://share.streamlit.io
3. Login dengan GitHub
4. Klik **New app** → pilih repo ini → `app.py`
5. Klik **Deploy**

## Cara Pakai
1. Buka link dashboard di atas
2. Upload file `.xls` dari RTI di sidebar kiri
3. Hasil scan muncul otomatis di tiap tab
